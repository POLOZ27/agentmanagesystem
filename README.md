# Johnathan Academy 代理管理系统（原型）

自托管的代理（Agent）管理系统：代理列表、佣金自动计算、新代理入驻、合同文件、邮件收发和定时 News 推送。
**所有业务数据只有掌握主密码的人能看到，服务器管理员、技术人员和备份都只能拿到密文。**

## 功能

| 模块 | 内容 |
|---|---|
| 总览 | 活跃代理、本学期佣金、未结清结算单（按流程阶段）、新代理入驻到第几步、该跟进的潜在代理、合同到期、最新来信 |
| 代理 | 全部代理一张表；详情含资料、等级、付款方式、合同、结算单、往来邮件 |
| 新代理入驻 | 7 步，每步在代理页面上直接操作（见下） |
| 学生申请 | 收到申请 → 资料齐全 → 已发录取信 → 已缴学费 → 学签获批 → 已入学；材料加密上传；已入学一键加入代理当学期结算单 |
| 合同 / 续签 | 按等级自动生成 Service Contract（Word）；到期前 120 天进续签列表，前 90 天自动按续签模板准备好新合同，检查后一键连同续签信发出；签回后新等级生效 |
| 佣金结算 | 一个代理一个学期 = 一张结算单，逐个学生明细，自动计算；5 个阶段（见下） |
| 开发新代理 | AI 联网搜索目标国家代理（规模等级 A/B/C + 联系方式）→ 审核 → 勾选后一键发英文 + 当地语言开发邮件 → 7 天未回自动提示跟进 → 谈成一键转为代理 |
| 邮件 / News | 给全部/活跃/选定代理发邮件，可设定期自动推送；收信自动归到对应代理或潜在代理，附件加密保存；邮件模板库 |
| 资料库 | 学校宣传资料（OneDrive 共享链接或上传文件）；写邮件时一键插入，Start Letter / 续签信自动带资料包链接 |
| 报表 | 代理业绩（按学年：学生数、第一年人数、学费、佣金、同比、申请→入学）；年度付款汇总和 T4A（加拿大个人/独资代理超过 $500，Box 020），导出给会计，一键给代理发年度付款明细 |
| 代理自助页 | 已做好，默认关闭：代理用邮箱验证码登录，只看自己的学生进度、结算单（可确认并上传发票）、合同到期日和宣传资料 |
| 设置与安全 | 学校邮箱 SMTP/IMAP、会计邮箱、AI 模式、资料包链接、T4A 付款方信息、NAS 加密备份、更换主密码、访问记录 |

### 佣金规则（来自 2025 版 Service Contract）
| | 标准级 Standard | 高级 Premier |
|---|---|---|
| 全日制第一年，同一学年 1–5 人 | 20% | 25% |
| 全日制第一年，同一学年满 6 人起 | 25% | 30% |
| 全日制第二年 / 第三年 | 10% / 5% | 10% / 5% |
| 兼职 / 单科（首次缴费） | 15% | 15% |
| AP（首次缴费） | 10% | 10% |

- 学年按 9 月到次年 8 月（暑校算在上一个学年），同一学生出现在多个学期只算 1 人。
- 达到 6 人时，本学年之前已经按低档发出的第一年学生，自动在本张结算单加一行「满 6 人补差」，不会重复补。
- 老代理（30%、25%、25/10/5 等旧合同）保留各自比例，没有 6 人档。
- 每个学生可以单独覆盖比例；「其它调整」可直接加减金额（退费等）。
- 历史 Excel 导入后，系统重算一遍，与 Excel 不同的标「需核对」（金额仍以 Excel 为准）。

### 佣金结算流程
1. **草稿**：上传 Student Roster Excel（现在用的 Commission Detail 表）或逐个填学生，系统自动算。
2. **发结算单**：先打开预览（邮件正文可改；附件是代理以前的 Student Roster + 本学期新加的工作表，每个工作表都能在网页上看），确认后发出，金额锁定。发出的这份 Roster 自动成为下个学期的底稿。
3. **代理已确认**：代理回信附发票，在收件箱里直接选附件登记。
4. **已交会计**：一键把对账单、发票、收款方和付款方式发给会计（只有付款需要的信息）。
5. **已付**：登记付款日期、参考号和凭证，自动给代理发付款通知。

### 新代理入驻 7 步
1. 初次联系（开发邮件）　2. 回复 / 线上会议　3. 申请表 + 背景核实　4. 确定等级　
5. 生成并发送合同（自动填好 + Start Letter）　6. 收回签字合同（加密上传）　7. 开通（编号、欢迎信、加入 News）

### AI 开发新代理
- 两种模式，在「设置与安全」里切换：
  - **本地（推荐）**：用学校服务器上已在运行的 llama-server（OpenAI 兼容接口）+ 自建 SearXNG 搜索，全部在服务器上完成，不经过外部 AI。流程：SearXNG 用英文和当地语言搜索 → 抓机构官网首页和联系页 → 本地模型判断是不是做高中留学的中介、分 A/B/C 级、整理联系人。邮箱和电话只采用网页上真实出现过的。
  - **Claude API**：效果更好（小语种网站、规模判断），需要 API Key；只发送「国家 + 搜索要求 + 要排除的机构名」。
- SearXNG 部署：`cd deploy/searxng`，把 settings.yml 里的 secret_key 换成 `openssl rand -hex 32` 的结果，然后 `docker compose up -d`（只监听 127.0.0.1:8888）。
- 本地模型地址填 llama-server 的 `/v1` 地址（容器 llama-server-vl 映射出来的端口），设置页有「测试 AI 连接」。
- 结果先进「待审核」，你勾选保留后才进入名单。
- 邮件模板库（邮件 → 邮件模板）：新版开发邮件、原短版、跟进邮件；`{name}` 联系人、`{agency}` 机构名。发邮件页面右上角按国家显示译文，可 AI 翻译并存回模板。
- 每封邮件末尾带学校地址和退订说明（加拿大 CASL 要求）；对方回复 unsubscribe 会自动标记，以后不再发。

## 隐私设计：为什么技术人员看不到数据

```
主密码（只在你脑中）──Argon2id──▶ 密钥加密密钥（不落盘）
                                   │ 解包
                                   ▼
                     数据密钥（只在服务器内存中）
                                   │ AES-256-GCM
                                   ▼
            代理资料 / 佣金 / 邮件 / 合同文件 / 邮箱密码（磁盘上全是密文）
```

1. **主密码不存储**：服务器只存盐和被包裹的数据密钥，没有主密码就解不开。
2. **两步验证**：登录需要主密码 + 手机验证器 6 位数（TOTP），验证器密钥本身也被加密。
3. **全部内容加密**：数据库每条记录是一段密文；合同文件在磁盘上用随机 ID 命名，看不出是谁的合同。
4. **重启即锁定**：服务器重启或点击「锁定」后，内存里的密钥清除，所有数据（包括定时邮件）都读不到，直到你本人登录解锁。
5. **恢复密钥**：首次设置时显示一次，离线保存（纸质或个人密码管理器）。忘记主密码只能靠它，技术人员无法重置。
6. 登录失败 5 次锁 15 分钟；30 分钟无操作需重新登录；访问记录只记事件，不含数据。

**仍需注意的边界**（请如实了解）：
- 能在服务器上取得 root 权限、并在系统**解锁运行期间**读取内存或替换程序代码的人，理论上仍可能拿到数据。
  建议：服务器（或云主机账号）由你本人持有 root/管理员密码；技术人员只负责部署代码，代码改动你可以让人审查后再上线；不用时点「锁定」。
- 定时 News 需要系统处于解锁状态才能发出（因为要读代理邮箱）。服务器重启后需要你登录一次才恢复推送。
- 一定要用 HTTPS（Caddy / Nginx 反向代理），本程序默认只监听 127.0.0.1。

## 在自己电脑上试用（Windows）

1. 安装 Python 3.11 或更新版本：https://www.python.org/downloads/ （安装时勾选 "Add Python to PATH"）
2. 解压 `agent-portal-prototype.zip`，在 `agent-portal` 文件夹地址栏输入 `cmd` 回车，打开命令行
3. 依次运行：
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python app.py
   ```
4. 浏览器打开 http://127.0.0.1:8800 ，按提示设置主密码、绑定手机验证器，然后就可以用了
5. 想先看演示数据：第 3 步最后一行换成
   ```
   set AGENT_PORTAL_DATA=demo-data
   .venv\Scripts\python demo_seed.py
   .venv\Scripts\python app.py
   ```
   主密码 `demo-password-123`，验证器密钥在 `demo-data\DEMO_TOTP.txt`（把它加进手机验证器）

## 运行（服务器）

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
AGENT_PORTAL_DATA=/srv/agent-portal-data .venv/bin/python app.py     # 默认 http://127.0.0.1:8800
```
首次打开会进入设置页：设主密码、绑定手机验证器、保存恢复密钥。

可选环境变量：
- `AGENT_PORTAL_BACKUP_DIR=/mnt/nas/agent-portal`：每天凌晨 2 点后把保险库（密文）打包复制到这个 NAS 目录，保留 14 天每日 + 12 个月每月一份。备份不需要解锁，锁定状态也会运行。
- `AGENT_SELF_SERVICE=1`：开放代理自助页 `/p/`。上线前需要真实邮箱（发验证码）和 HTTPS 域名。

### 从备份恢复
把备份 tar 解开到新的数据目录（得到 `vault.db` 和 `files/`），用 `AGENT_PORTAL_DATA=<该目录>` 启动，输入原来的主密码 + 验证码（或恢复密钥）即可。没有主密码，备份打不开。

导入现有 Excel 和合同文件名（合同到期日从文件名里的 `until 2028 Oct` 读取）：
```bash
.venv/bin/python importer.py "代理表 last update July-16-26.xlsx" 合同文件名列表.txt
```

## 文件
- `vault.py` 加密保险库（密钥层级、记录/文件加解密、审计）
- `commission.py` 等级、比例和佣金计算（含满 6 人补差）
- `statements.py` 对账单 Excel、读取 Student Roster
- `contracts.py` 按等级生成合同；`contract_templates/` 合同母版
- `email_templates.py` 结算、会计、付款通知、Start Letter、欢迎信等模板
- `outreach_i18n.py` 开发邮件 / 跟进邮件和各国语言版本
- `ai.py` AI 模式切换、Claude 联网搜索和翻译
- `local_ai.py` 本地模式：llama-server + SearXNG
- `deploy/searxng/` 自建搜索的 docker compose
- `importer.py` Excel / 合同文件名导入
- `mailer.py` SMTP 发信、IMAP 收信、定时推送
- `backup.py` NAS 加密备份（SQLite 在线快照 + 加密文件，按天/月保留）
- `tax.py` 年度付款汇总、T4A 判断和导出
- `portal.py` 代理自助页（默认关闭）；`templates/portal/`
- `app.py` 网页（Flask）
- `demo_seed.py` 生成虚构演示数据
